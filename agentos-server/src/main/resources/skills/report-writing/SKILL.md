# 技术报告写作指南

## 步骤

1. **明确读者与目的**：先确认报告面向的读者（技术/管理层）与要回答的核心问题。
2. **收集素材**：用检索或文件读取工具收集事实依据，记录来源，不臆造数据。
3. **搭结构**：按「结论先行 → 背景与问题 → 分析过程 → 建议与风险」组织章节。
4. **成文**：每个论点必须携带证据（数据、引用或观察结果）。
5. **收尾检查**：结论与开头呼应，列出未决事项与后续行动。

## 约束

- 报告语言跟随用户提问语言。
- 涉及不确定的信息必须标注置信程度。
- 输出为 Markdown，章节层级不超过三级。

## 输出格式

```
# <报告标题>
## 结论
## 背景与问题
## 分析
## 建议与风险
```
